# صفحه‌ی سورپرایز 💖

## اجرا
1. Node.js نسخه ۱۸ یا بالاتر نصب باشد (نیاز به نصب پکیج ندارد).
2. عکس بک‌گراند را با نام `bg.jpg` داخل `public/images` بگذارید.
3. در پوشه پروژه اجرا کنید: `node server.js`
4. صفحه‌ی اصلی: `http://localhost:3000`
5. پنل ادمین: `http://localhost:3000/admin.html` (یوزر: ronin، رمز: 338161)

## نکات
- همه‌ی کلیک‌ها و جواب‌ها در `data/data.json` ذخیره می‌شوند.
- رمز ورود صفحه‌ی اصلی `mobina.kj` است و در `public/index.html` با متغیر `PASSWORD` قابل تغییر است.
- برای اینکه از بیرون هم قابل دسترس باشد، روی یک هاست مثل Render یا VPS اجرا کنید. یا برای تست موقت از ngrok استفاده کنید.
- یوزر و رمز ادمین را می‌توانید با متغیرهای `ADMIN_USER` و `ADMIN_PASS` عوض کنید.
